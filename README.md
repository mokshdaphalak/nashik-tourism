# Explore Nashik - Responsive Website

## About the Project
Explore Nashik is a responsive tourism website created
using HTML and CSS for Assignment-15.

## Pages
1. Home - Introduction and featured destinations.
2. Places - Six tourist destinations in Nashik.
3. Contact - Contact information and a message form.

## Technologies Used
- HTML5
- CSS3
- CSS Media Queries
- Git and GitHub
- Netlify

## Responsive Features
- Desktop, tablet and mobile layouts
- Mobile navigation toggle
- Responsive destination cards
- Flexible images
- Responsive contact form
